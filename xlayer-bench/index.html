English
Swap NAND/LATCH brains and inspect measured state transitions. The default brain has 4,850,059 NAND gates and 643 latches; its netlist is off-chain and runs in your browser. Free-form answers and semantic tool arguments are unreliable; numeric arguments may replay zero. Tiny recall and tool-summary circuits are available in the brain picker. The tool summary captures and replays structure, not natural-language understanding. An unconfigured TapeOut identity is pending, not a deployment claim.

范围、来源与旧工具验证（不代表 X Layer 部署）

Pi 派生工作台；语言网表在链下，浏览器按门求值；这里只发布页面和一个小电路。
默认核心为 4,850,059 NAND + 643 LATCH。工具摘要是结构化捕获/回放，不是自然语言理解。
现有核心不保证相关回答；生成长度上限不等于模型自行停止。


nand_step 是已有的 386 NAND 导航工具；其链上交叉检查仍在 BNB，不能算作 X Layer 流片证据。
原始工作台及依赖署名见 NOTICE / licenses。

 NAND tool: checking netlist…



A derivative of the Pi browser workspace · MiniCPM5-2B Space (upstream by townbox, Apache-2.0). Changed here: the model is replaced by impossible LLM, a 4,850,059-NAND / 643-LATCH NAND netlist transcribed from OpenBMB MiniCPM5-2B, and one tool is added: nand_step.
 Agent Pi · Shell just-bash · Tokenizer MiniCPM5 (Transformers.js).
