# 吟游诗人芯片

> 一个语言模型直接做成一颗芯片。现在这一版写儿童故事风格的英文句子，常不连贯、人物会乱，有时会出现 ⁇（模型不认识的词）。我们正在研究把它升级成能讲连贯故事的新芯片，还没做到。设计图已存上 X Layer，还没送厂生产。

::: buttons
- [在应用里看它写几句、取回设计图](../app/#bard)
- [从链上取回设计图（网关页）](https://1-2-245.aihashrate.stream/bard/v8g/)
:::

## 它是什么

- 芯片里没有处理器，也没有程序。模型学到的东西刻在电路里，通电就能写字。
- 模型来自 tiny-tiny-stories（MIT 许可），写儿童故事风格的英文句子，常不连贯、人物会乱。
- 设计全用开源工具，工艺是 SkyWater SKY130。
- 完整设计图存在 X Layer 上，谁都能取回来逐字节核对。

## 签核结果（v8g）

| 检查 | 结果 |
|---|---|
| KLayout DRC | 0 |
| Netgen LVS | 一致（Circuits match uniquely） |
| 天线（OpenROAD 检查） | 0 个网 |
| 建立时间，九个角 | 0 违例，最差余量 26.73 ns |
| 保持时间，九个角 | 0 违例，最差余量 0.0509 ns |
| 布线后网表回放 | L1→32（2,499,420 拍）、L2→5（5,612,207 拍）、L3→128（9,418,594 拍），和参考实现相同 |

> 这些都是版图工具和仿真算出来的结果。芯片还没造出来，没有实测数据。

> 天线这一项的范围：查的是补填充之前的那份版图；它和后来签核的那份 GDS 之间没有用哈希对上，凭当时的记录是同一份。用的是单元库里的天线数据，不是晶圆厂的签核工具。

## 做到哪了

- 2026-10-12：设计通过全部制造规则检查，设计图存上 X Layer。
- 在哪造、什么时候造，还没定。
- 同一份网表在七个平台上做完了布局布线，见[工艺阶梯](nodes.md)。
- 整机在 XC7A100T FPGA 上布线通过，时序 21.19 MHz，见 [FPGA 移植](fpga.md)。还没上实物板。
- ESP32-S3 固件用同一套整数规则写句子，在电脑上和标准实现对过 12 组，全部一致，见[故事机](storybox.md)。还没上实物板。
