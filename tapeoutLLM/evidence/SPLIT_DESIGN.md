# Multi-circuit split for the 19.6k g44 model (design)

Primary information: the 19,567-NAND g44 netlist exceeds the mainnet 40,061 B (5,723-record)
tape-out cap, so it splits into 4 circuits of 5,723 / 5,723 / 5,723 / 2,398 records. Chained
evaluation of the 4 slices reproduces the original netlist bit-for-bit (0/2000 random inputs,
verified by split_design.py).

Required context: each slice is an independent TapeOut circuit built by slicing the combinational
DAG along topological levels and remapping wire ids. A container contract feeds the user's
192-bit context into slice 0, stores the exported wires, and feeds each later slice the
intermediate wires it needs. Cut widths: slice 0 -> 1: 2,324 wires, 1 -> 2: 1,905, 2 -> 3: 731
(4,960 intermediate wires total). Only 24 primary inputs are ever read - the last 4 characters -
because g44 is a 4-gram table and the other 28 context characters are dead inputs.

Container (Solidity sketch): read 192 context bits; for each slice i, pack [the wires it needs in
the slice's local input order] as bytes, call Circuits.step(cid_i, "", packed), store the exported
wires in memory, repeat; return the last 6 wires of the final slice. Memory holds <= 3,069
exported wires (<= 384 bytes), so the container stays tiny.

Gas per character (model, measured slope 2,293/NAND + 60k/hop overhead): 4 x 13.18M + 5.56M =
45.1M step gas (0.66 block), vs the single-circuit 45.7M measured but unburnable; burn =
2,923 x 19,567 = 57.2M gas across 4 tape-out transactions, each <= 5,723 records and <= 40,061 B.
The split adds ~0 gas to the step (each slice runs in the linear regime) and ~11.5M to the burn
(vs one 19,567-record tape-out that mainnet rejects).

Next judgement: record the 300k point, or implement and test the container (local, read-only)
against the 4 slice circuits before any burn decision.

Artifacts: split_design.py (slicing + verification), netlist_resyn_g44_resyn.json (source).

## Container evidence (local, 2026-09-14)

G44Container.sol (generated by gen_container.py, 4,939 B code, wiring blob 39,456 B in storage) was
tested on a fresh PyEVM CPU with the 5 slice circuits taped out: run() matches the single g44 netlist
on 0/5 random contexts (after fixing a bytes6 byte-order bug in the result assembly; emit_slices.py
chain is 0/2000). Container run gas = 72,655,025 (estimateGas 72,933,648) = 1.06 blocks. Slice tape-out
burn gas: 15,440,825 / 13,917,240 / 11,962,480 / 11,705,876 / 10,453,371 (sum 63,479,792, vs the
single-netlist 56,976,135 that mainnet rejects). Artifacts: emit_slices.py, gen_container.py,
container_wiring.hex, test_container.py, container_test.json, netlist_resyn_g44_slice{0..4}.json.
