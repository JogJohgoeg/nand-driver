impossible LLM v2 — 5,142,875 个 NAND 门的语言模型a language model made of 5,142,875 NAND gates

它读最近 6 个 MiniCPM5 token 和 4 个随机位，一次求值输出下一个 token；这一页在你的浏览器里逐门计算，没有后端。 v2 相比 v1：不再掉进 “the 2008 , the 2008” 这类死循环（采样时 0%），在对话、网页、中文文本上的一致率分别是 v1 的 4.1、2.1、53 倍。 它仍然写不出连贯的句子，也没有上链。It reads the last 6 MiniCPM5 tokens plus 4 random bits and outputs the next token in a single evaluation; this page computes it gate by gate in your browser, with no backend. Compared with v1, v2 no longer falls into loops like “the 2008 , the 2008” (0% when sampling), and its agreement with the teacher on chat, web and Chinese text is 4.1×, 2.1× and 53× that of v1. It still can't write coherent sentences, and it is not on-chain.

每个 token：取文本最后 6 个 token（102 位）+ 4 个随机位 → 5,142,875 个门 → 13 位编码 → token。随机位来自浏览器的 crypto.getRandomValues；勾选「贪心」后恒为 0，输出只由文本决定。Per token: the last 6 tokens of the text (102 bits) + 4 random bits → 5,142,875 gates → 13-bit code → token. The random bits come from the browser's crypto.getRandomValues; with “Greedy” checked they are always 0, so the output depends only on the text.

怎么验证的How it was verified

  • 网表和查表语义逐位一致：全部 293,717 个表项 × 16 种随机位、20 万条随机输入、四个来源各约 20 万条测试窗口，0 处不一致（C 位并行求值器）。The netlist matches the lookup-table semantics bit for bit: all 293,717 entries × 16 random-bit values, 200K random inputs, and about 200K test windows from each of the four sources, with 0 mismatches (bit-parallel C evaluator).
  • 上面的一致率是用网表本身的输出算的，和建表程序的数字逐位相同。The agreement rates above are computed from the netlist's own outputs and are identical to the table builder's numbers.
  • 这一页用的 JavaScript 求值器在 4,000 条输入上与参考语义 0 处不一致；分词和打包与离线流程在 200 条参考提示上一致。The JavaScript evaluator on this page has 0 mismatches against the reference semantics on 4,000 inputs; tokenization and packing match the offline pipeline on 200 reference prompts.

它做不到什么What it can't do

  • 写不出连贯的话。它只看最近 6 个 token，本质是一张教师答案的回退查表；句子常常在中文、英文、代码之间乱跳（四种语料混在一起训练的结果）。It can't write coherent text. It only sees the last 6 tokens and is essentially a back-off lookup table of the teacher's answers; sentences often jump between Chinese, English and code (the result of training on four mixed corpora).
  • 采样只是不重复，不是更聪明。任何「只看最近 6 个 token 的确定性网表」都终究会循环，v1 在 80 条提示上全部卡住；给表项换答案只会把环挪个位置（在只用维基的试验表上实测：改 60 处后 800 个起点仍全部被困），所以 v2 改用随机位。Sampling only avoids repetition; it isn't smarter. Any deterministic netlist that sees only the last 6 tokens will eventually loop, and v1 got stuck on all 80 prompts. Changing the answers in table entries only moves the loop somewhere else (measured on a Wikipedia-only trial table: after 60 edits all 800 starting points were still trapped), so v2 switched to random bits.
  • 偶尔出现 “�”。汉字由几个字节 token 拼成，模型有时只输出了其中一部分就转去别的 token。Occasional “�”. A Chinese character is made of several byte tokens, and the model sometimes outputs only some of them before moving on to a different token.
  • 离教师还很远。最好的来源也只有约 0.31，教师约 0.49。门数每翻一倍大约只多 0.014，再往上主要靠更多训练数据，而不是更多门。Still far from the teacher. Even the best source reaches only about 0.31, versus about 0.49 for the teacher. Each doubling of the gate count adds only about 0.014; further gains will come mainly from more training data, not more gates.
  • 不会调用工具、没有记忆、没有上链。No tool use, no memory, not on-chain.
