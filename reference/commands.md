# 可核对命令

> 链上的和我们发布的东西，每一条写清核什么、凭什么、用哪条命令、通过时看到什么。全部只读，不用钱包。

> tapemule 命令行的仓库现在还没公开，下面用到它的命令要等仓库公开后才能照做。不用它也能核对单个文件：见[快速上手](../start/quickstart.md)。
## 先装好

```sh 下载 tapemule 并装依赖（要 Node.js 22 或更新）
git clone https://github.com/BruceLanLan/tapemule.git
cd tapemule
npm ci
```

下面 tapemule 的命令都在这个目录里跑。每次读链都钉在终局块，至少两家独立节点给的结果一致才算数。

## 一览

| # | 核什么 | 凭什么 | 命令 | 通过时 |
|---|---|---|---|---|
| 1 | 三条链上的中枢合约（Hub）是钉住的那份实现 | 链上代码和实现地址，和 tapemule 里钉的一致 | `npm run tape -- hub bnb`（`base`、`xlayer` 同理） | `核对通过`，退出码 0 |
| 2 | 一个 `.tape` 站点：容器、持有人、激活，每个文件的字节和链上登记的指纹一致 | 每个文件链上登记的 sha256 | `npm run tape -- open <名字> --files` | 每个文件一行 `verified`，退出码 0；有一个不是就退出 1 |
| 3 | 手上一个本地文件就是某站点某路径登记的那份 | 那个路径链上登记的大小和 sha256，只读登记、不下载内容 | 还没合进 tapemule 主分支 | `verified`，退出码 0；改一个字节是 `incomplete`，退出 1 |
| 4 | TapeBoot 规范化、签名、取回的测试向量（C 版） | 测试向量，不含私钥 | 脚本未公开 | `全部通过：0 处失败` |
| 5 | 同一组测试向量（TS 参考客户端） | 同上 | 脚本未公开 | 14 条全部通过 |
| 6 | 10 颗链上电路的网表：链上存的 = 烧录交易里的 = 我们仓库里留的 | 链上 `netlist(id)` 和 `circuitInfo(id)`；烧录交易的输入和收据；仓库里的网表文件。三方比 sha256 | 脚本未公开 | 每颗一行，三个 sha256 前 12 位加 `一致`；全部一致退出 0，有不一致或读不到退出 1，没有不一致但有一颗缺一方退出 2 |
| 7 | 模型机玩具模型和它写出的字 | 文件 sha256 和输出 sha256 | 打开[模型机](../machine/index.md)，点「写 200 个字」 | 两个 sha256 和页面上写的一致 |

## 1. 中枢合约

```sh 核对三条链的中枢
npm run tape -- hub bnb && npm run tape -- hub base && npm run tape -- hub xlayer
```

- 每条链打印 `核对通过`，退出码 0。
- 没通过时打印 `没通过（原因）`，退出码 1。
- 地址见[合约地址](contracts.md)。

## 2. 一个站点的每个文件

```sh 逐个读 282.732.tape 的文件，和链上登记的 sha256 比
npm run tape -- open 282.732.tape --files
```

- 先打印容器、持有人、激活到哪天、钉在哪个块、哪几家节点一致、文件数。
- 然后每个文件一行：结论、路径、字节数。
- 结论只有 `verified` 算通过。其他三种：`unverified`（链上没登记指纹）、`incomplete`（长度或哈希对不上）、`missing`（链上没有这个路径）。
- 换成 `1.2.245.tape` 核吟游诗人设计图所在的站点。

```sh 同样的结果输出成 JSON
npm run tape -- open 282.732.tape --files --json
```

## 6. 链上电路网表

| 电路 | 链 | 处理器 |
|---|---|---|
| 279.732 到 287.732，共 9 颗 | BNB Chain | CPU #732 |
| 3.2.245 | X Layer | #245 |

282.732 这里只核电路网表，它的网站文件用第 2 条核。

脚本还没公开。没有脚本也能自己核：

1. 对处理器合约 `eth_call` 读 `netlist(id)`，算 sha256。
2. 找到这颗电路的烧录交易，按 `tapeout(bytes,uint32,uint32)` 解出网表字节，算 sha256。收据要 status = 1、发给这个处理器、有 `TapedOut(id)` 事件。
3. 两个 sha256 相同，就是链上存的和当初烧进去的是同一份。

网表字节怎么排，见[网表格式](netlist.md)。

## 其他只读命令

```sh 列出一条链上的站点并查激活（BNB 要几分钟）
npm run tape -- sites bnb
```

```sh 在站点数据里按关键词搜（不读链）
npm run tape -- search 电路
```

所有命令加 `--json` 输出 JSON。
