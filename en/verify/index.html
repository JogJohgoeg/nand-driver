Check it yourself

You don’t have to take our word for anything. Everything below is on chain, and you can fetch it and recompute it yourself.

THREE WAYS TO CHECK, FROM EASY TO EXPERT

  1. Open it through an official gateway. TapeOut’s official gateways read every file from the chain and check each byte, for example this site at 282-732.tapekit.org. If it looks the same as what you see here, the content came from the chain.
  2. Compute the fingerprint. Each file’s sha256 fingerprint was recorded when it went on chain. Download the file, run any sha256 tool on it and compare with the values below.
  3. Call the contracts directly. Web files are recorded in the site registry 0xd006ffdd5ae313b17729621a00999cd3c71ce5e6 (BNB Chain); fileInfo(container, path) returns the size and fingerprint. Circuits can be run directly with eval; see the 21-gate driver below.
