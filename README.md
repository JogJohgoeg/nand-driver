# 21 NAND Driver

A 13-gate differentiable logic gate network (DLGN) car controller, lowered to 21 NAND gates and burned as circuit #279 on a TapeOut CPU on BNB Smart Chain.

- CPU: `0x6Fb4089e7Cbaa9660Fd11056274Cbd8117EE5B38`
- circuitId: 279
- tx: `0xc6eaa6616968fc6f7ffa8058d18d55e26a06469e9e866ce07636d94e33754a6e`

Open `index.html` (or the GitHub Pages site) to watch the car drive; press "Use on-chain eval" to have every steering decision computed by a BSC node from the on-chain netlist.
