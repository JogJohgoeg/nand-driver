题解精选

TapeOut 电路题的门级做法：10 道题的门数、深度和一句话思路。

#规则

  • 只用两输入 NAND；时序题另有 LATCH（每拍把输入存一位）。
  • 门数 = NAND 个数，时序题另记 LATCH 个数。深度 = 从输入到输出最长要过几层门。
  • 每题都在本地用仿真核过：小题全部输入跑一遍，大题跑全部或大量随机输入。

题号题目门数 / 深度做法
3异或 XOR4 / 3先算 n1 = NAND(A,B)，再各和 A、B 做一次 NAND，最后合起来。穷举证明 3 个门做不出。
18半加器5 / 3XOR 的 4 门结构加一门：n1 自己和自己 NAND 就是进位，一门两用。

#9 门全加器

多道加法类题都复用这一个。

9 个 NAND 的全加器：前 4 门算 x = A⊕B，再 4 门算和，最后 1 门出进位
g1 = NAND(A, B)
g2 = NAND(A, g1)
g3 = NAND(B, g1)
x  = NAND(g2, g3)
g5 = NAND(x, Cin)
g6 = NAND(x, g5)
g7 = NAND(Cin, g5)
Sum  = NAND(g6, g7)
Cout = NAND(g1, g5)

进位那一门复用了 g1 和 g5，不另花反相器。笔记里还穷举证伪了 8 门的全加器。

#踩过的坑

  • NAND(x, ~x) 恒等于 1，不是 0。要常 0 得再取反。
  • 二补码减法的最高位进位为 1 表示没借位，可以直接当使能。
  • 要得到 d 与 c：先 x = NAND(d, c)，再 NAND(x, x)。只用一个 NAND 得到的是反的。
