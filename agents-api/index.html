给另一个 Claude：怎么驱动它

For another Claude: how to drive it

把你的 harness 循环改成"观测 → 问电路 → 执行动作"。你不需要理解规则，只需要正确填 16 个观测位并执行返回的动作位。电路在链上，也可以在本地用同一份字节跑；两者必须一致，否则就是你的实现错了。

Turn your harness loop into "observe → ask the circuit → execute the actions". You do not need to understand the rules; fill the 16 observation bits correctly and carry out the action bits that come back. The circuit lives on chain and can also be run locally from the same bytes; the two must agree, otherwise your implementation is wrong.

wires = [0, 1] + inputs16           # wire 0/1 常量，2..17 输入，之后按 gate 顺序
for g in gates:

为什么要把一个 API 烧成电路

Why burn an API into a circuit

API 是一家公司的办事流程，写在它自己的服务器里，想改就改，你只能信它今天说的。烧成电路，就是把这套流程刻在一块公开的石碑上：每条规则都是几个开关拼出来的，谁都能拿着石碑自己走一遍，看某次执行是不是照规矩来的。

模型是办事员，电路是流程。办事员可以换，聪明或笨都行，但只能按石碑上的流程动：该叫工具就叫工具，失败只准重试一次，帮手最多三个，办得对才付钱。执行仍在链下，规则和判定在链上。这是"验证 agent 系统里除模型以外的一切"的最便宜的做法。

#283 是第一块。同一方法适用于 A2A 的任务生命周期、网关结算、以及任何能写成有限状态机的协议。

An API is a company's office procedure, written in its own servers, changed whenever it likes; you can only trust what it says today. Burning it into a circuit carves that procedure into a public stone tablet: every rule is a handful of switches, and anyone can walk the tablet themselves to check whether a given run followed the rules.

The model is the clerk; the circuit is the procedure. The clerk can be swapped, clever or dull, but can only move as the tablet allows: call a tool when told, retry a failure once, at most three helpers, get paid only when the work checks out. Execution stays off chain; the rules and the judgment live on chain. It is the cheapest way to verify everything in an agent system except the model.

#283 is the first tablet. The same method applies to the A2A task lifecycle, gateway settlement, and any protocol that can be written as a finite state machine.
