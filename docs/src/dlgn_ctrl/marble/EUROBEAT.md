# Original Eurobeat and browser-only music

The composition is original: no recording, melody transcription, lyrics or samples from the named reference track are used. It draws only on broad Eurobeat instrumentation and energy.

158 BPM,4/4,32 bars: intro4 / verse8 / pre4 / chorus8 / break4 / chorus4. It starts in E minor and rises one semitone to F minor at the chorus. An independently written eight-bar brass hook has a four-bar call and four-bar response. The score combines four-on-the-floor sine-drop kicks, bright layered claps on2/4, offbeat open hats, octave-jumping sixteenth-note saw bass, offbeat chord stabs, sidechained pads, wordless parallel-formant saw counter-melody, and accelerating snare rolls/noise risers. The original25ms/150ms audio-clock lookahead scheduling scheme remains; the32-bar form wraps without resetting active release tails. Music remains off by default behind the same b-music / mus_on / mus_off controls.

“Use my own music” (b-mymusic / mym_on) opens a hidden accept=audio/* picker. Selection is decoded with decodeAudioData, held only in RAM and looped through the same music bus/master. A modest RMS-based trim limits loud user files; local audio bypasses the synth pad sidechain. The synth scheduler and all its active voices stop while the file plays. The existing Music toggle controls either source; “Use Eurobeat” clears the decoded file and returns to the original score. Invalid files show an inline localized error while leaving the current music usable. A cancelled picker does nothing. File names are shown with textContent, never HTML.

There are no uploads, object URLs, localStorage/IndexedDB writes or file persistence. Leaving3D or hiding the tab stops the local source and suspends playback; returning restarts the selected loop. Reloading clears the file selection. Decode requests use a sequence guard so an older selection cannot replace a newer one; turning music off during a pending decode cancels its activation.

It observes **zero network requests** during file selection/playback and unchanged browser storage. Results: eurobeat_validation.json / .txt. Both inline scripts pass node --check.
