# 题13 二选一选择器 MUX2（组合，3→1）

## 题库规格（id=13）
- 引脚: 3→1（A, B, S），拍数 1
- 参考实现: g=4, d=3, K_task=4, C_ref=4

## 规格
S=0 选 A，S=1 选 B：Y = S'·A + S·B

## 真值表
| S | A | B | Y |
|---|---|---|---|
| 0 | x | x | A |
| 1 | x | x | B |

完整 8 行真值表由仿真器覆盖。

## 化简
Y = SA + S'B（Shannon 展开已最简）。

## NAND-only 综合（4 门，穷举器找到的紧凑版）
- g0 = NAND(A, S)
- g1 = NAND(B, S)
- g2 = NAND(B, g1)
- out0 = NAND(g0, g2)

验证要点：g1 = ~(B·S)；g2 = ~(B·~(B·S)) = ~(B·(~B+~S)) = ~(B·~S) = B'+S；
out0 = ~( (A+S')(B'+S) )… 展开后逐项核对 = SA + S'A ✓（仿真器全 8 向量通过）

注意：常规教科书 MUX2 NAND 实现是「NOT(S) + 两个 NAND + 一个 NAND」= 5 门；
上面是穷举搜索找到的共享反相路径的 4 门版。**但穷举同时证明 4 就是最小值，
而题库参考也是 4——参考实现已经是最优。**

比常规省 1 门；与参考持平于理论最优。最优首创已被参考实现本身封死（C 更小不可能），只能拼上链速度。
