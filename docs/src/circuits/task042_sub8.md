# 题42: 8 位减法器带借位 — 持平（无溢价，可缓上）

## 规格
- A(in0..7) - B(in8..15) - bin(in16) → diff(out0..7, LSB first) + borrow(out8)
- ref g=82

## 结构
二补码：A + ~B + (~bin)，每位 FA9 + B 反相 1 门 = 10 门/位 × 8 + borrow 取反 + 位0 的 nbin/nb0 复用计 2 门 → **82 门 = ref**。

## 结论
持平无首创溢价。若后续需要减法核（如 #71 ALU、#226 饱和加），此结构可直接复用。
