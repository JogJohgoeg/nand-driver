# 任务 #226 — 8 位饱和加法（无符号, a+b 溢出截断到 255）

## 规格
- nIn=16 (A=in0..7, B=in8..15), nOut=8
- 语义: out = min(a+b, 255)
- 参考最优: 85 门

## 结果: 放弃（不上链）
- v1 (FA9×8 + 掩码 NAND(~s_i,~cout) + 常0造3门): **92 门 (+8.2%)**, 全65536向量 PASS
- v2 (首位 HA5 特化 + 7×FA9): **88 门 (+3.5%)**, 全65536向量 PASS (`_scratch/solve_shift226_v2.py`)
- v3 理论分析: 掩码每位固定开销 ~sum 取反1门 + NAND 1门 = 2门/位=16门,
  加法核下界 HA5+7FA9=68 门, 结构总下界 ~87 门 > 参考 85。
  除非找到 ~s 免费信号或更省的 OR 形式, 否则无法打平。

## 踩坑记录
- NAND(x, ~x) = 常**1** 不是常0! 造常0需再取反（3门）或复用现成反相信号对。
- FA9 中 NAND(g6,g7) 输出的是 sum 本身（正相），不是 ~sum。

## 复用价值
- 饱和掩码结构可复用于其他饱和类题; 减法核(#42/#43)已证可复用。
