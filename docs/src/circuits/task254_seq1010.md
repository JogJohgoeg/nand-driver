# 题254: 序列检测 1010（中级, seq, 1入1出, 16拍）

与题83 同族。两种方案:
- FSM-BFS: 正确位序下 ≤6 NAND 无解（audit_seq.py）, 预计 ≥7N+2L=9 门
- 移位检测: out = ~x·d2·~d1·d0, 7 NAND + 3 LATCH = **10 门**（参考 g=11, -9%）

推荐先用 BFS 扩到 7 NAND 确认 9 门解是否存在; 若画布时间紧直接上移位结构 10 门。
注意 ~x 与 ~d1 需要显式反相门（平台 LATCH 是否免费给 Q̄ 待确认——若给, 移位结构降到 8 门）。

验证: batch2_verify.py 框架, ref 模式改为 (1,0,1,0)。
