# 题22: 3-8 译码器（初级, comb, 3入8出）— 最优首创候选 ★

## 规格
- 输入 in0=A0, in1=A1, in2=A2
- 输出 Y0..Y7 独热高有效: Y_i=1 当且仅当地址=i
- 题库参考 g=27, d=5, K=27

## 推导
教科书: 3 反相 + 8×NAND3。NAND3 用 2输入NAND 展开需 4 门/输出 → 约 35 门。
共享优化（本设计, solve_task022.py build()）:
- 层1 反相(3): p_i = NAND(A_i,A_i) = ~A_i
- 层2 或(3):   or_ij = NAND(p_i,p_j) = A_i+A_j
- 层3 对与(3): q_ij = NAND(or_ij,or_ij) = ~A_i·~A_j
- 补正对(2):   t01=NAND(in0,in1)=~A0+~A1; r01=NAND(t01,t01)=A0·A1
- 输出级(16):  每 minterm = (对与 or 正对) × 单字母，AND 用 2 门:
    Y000=~(~(q01&p2)); Y001=~(~(q01&in2)); ... Y110=~(~(r01&p2)); Y111=~(~(r01&in2))

## 门数
**27 门**（19 中间 + 8 输出级），全 256 向量仿真 PASS。

## 与参考对比 & 首创可行性
