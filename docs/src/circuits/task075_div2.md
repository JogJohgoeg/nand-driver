# 题75 二分频 Divide-by-2（时序，1→1，8 拍）

## 题库规格（id=75）
- 引脚: 1→1（输入 T 类时钟，输出 Q），cycles=8
- 参考实现: g=2, d=1, K_task=2, C_ref=2
- 时序规则：从全 0 状态起跑，逐拍比对输出

## 规格
输出频率 = 输入的一半：Q(t+1) = Q(t) 的翻转，即 Q 序列 0,1,0,1,…

## 状态推导
状态只有 Q∈{0,1}，转移表：
| Q(t) | Q(t+1)=D |
|---|---|
| 0 | 1 |
| 1 | 0 |

D(Q) = Q' —— 激励方程就是一个反相器。

## NAND + LATCH 综合（2 元件）
- d = NAND(q, q)      —— 反相器（1 个 NAND）
- q = LATCH(d)        —— 心跳时 q <= d

**门数 = 2（1 NAND + 1 LATCH），深度 = 1**

## 门数对比
| 实现 | 门数 |
|---|---|
| 本设计 / 题库参考 / 理论最优 | **2** |

理论最优性论证：要产生翻转必须有一个存储位（≥1 LATCH）和一个求反元件（≥1 NAND）；1 元件不可能既存又算。故 2 是下限，本设计触及下限。

## 结论
与参考持平于理论最优，首创空间为零。这是全题库最小的时序电路，K_task 也最低（=2），
工本小、收益小，适合作为画布/LATCH 语义的练手题和冒烟测试。

## 本地验证
`python3 verify_seq.py` → 二分频 8 拍序列 [0,1,0,1,0,1,0,1] PASS（从全 0 起跑逐拍比对，与平台规则一致）。
