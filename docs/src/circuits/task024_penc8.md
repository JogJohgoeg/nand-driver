# 题24: 8-3 优先编码器（中级, comb, 8入3出）

## 规格
- 输入 in0..in7，in7 优先级最高
- 输出 (out2,out1,out0) = 最高有效请求位的二进制编号
- 全零输入约定输出 000（画布阶段需实测平台对全零的定义）
- 题库参考 g=44, d=14, K=44

## 结构推导（分层 + 组内复用）
1. 分组：高组 U={i7..i4}，低组 L={i3..i0}
2. 组内 4 位优先编码 enc4([a,b,c,d])：
   - e1 = a + b·~a          （a→11, b→10）
   - e0 = a + c·~(a+b)      （c→01, d→00）
   - any = a+b+c+d
   - NAND 恒等式: or(x,y) = NAND(~x,~y)，and(x,y) = ~NAND(x,y)（自反相）
3. 顶层: y2=anyU; y1=MUX(anyU; e1U,e1L); y0=MUX(anyU; e0U,e0L)

## 门数统计
实测网表共 **78 门**（含全部反相/与/或/MUX 展开为 2输入NAND）。
全 256 向量仿真 PASS（solve_task024_penc8.py）。
