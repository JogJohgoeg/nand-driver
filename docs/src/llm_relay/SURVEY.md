The text path is `TokenAuth → Distribute → RelayTextHelper → preConsumeQuota → adaptor.DoRequest/DoResponse → postConsumeQuota`; errors return to the outer retry loop. The source explicitly refunds on HTTP/response errors, while some earlier conversion/transport error returns lack that explicit refund in this function. Our controller instead makes reservation release an explicit terminal action. / 电路把每次终结的释放预占动作显式化。

First circuit intentionally differs from One API: two model classes/channels, one alternate-channel retry, A-only two-failure breaker with three explicit cooldown ticks, a 0–3 unit customer tariff and three-unit reservation. It does not claim byte-for-byte One API semantics. v2 supplies bit-parallel semantics and exhaustive mapping checks; v3/v4 supply bounded retry/termination discipline; v5 supplies multi-bit billing action gating. `gateway_demo` supplies the replayable decision/ledger architecture. The v5 report records 295 NAND + 23 LATCH; the task card's 147/10 figure describes the earlier controller, not v5.
