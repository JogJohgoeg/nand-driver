# 取指环 B 档 what-if（D-40，11-01，本机，不占 build-host）

输入：top_e3 的综合网表 `work/results/ics55/top_e3/base/1_2_yosys.v`（body = `/h2/mrom9/body.v`，v8g）。脚本都跑 `python3 X.py 1_2_yosys.v`，依次复用 cone.py 的解析。

| 脚本 | 量什么 | top_e3 结果 |
|---|---|---|
| cone.py | 列底地址扇入锥 / 列顶字扇出锥 | 337（55 个寄存器 F + 282 组合）/ 4395 单元，互不共享寄存器 |
| retime.py | F 的输出去向、地址锥的输入、F 的下一态是否用到 ROM 字 | F 另有 128 个负载；地址锥只吃 F；F 的 D 锥不碰 ROM 字 |
| lookahead.py | 地址往前推几拍仍与 ROM 字无关 | 第 1–5 步无关、第 6 步才碰；但第 1 步起就用到外部 din |
| comp.py | 重定时后进新地址寄存器的组合深度 | 61 级（地址锥 32 级、F 的 D 锥最深 34 级；body 现有最深 51 级） |
| seg.py | 时序报告最差路径分段 | 见 NODE_PHYS |

结论：在地址锥输出加 15 位寄存器 A（D = 地址锥作用在 F 的 D 网上，复制 282 个组合单元，F 保留），
是纯重定时，逐拍行为不变（除第 0 拍 A 的初值）；取指环的最长路径变成 A→ROM→字扇出锥→寄存器。
再往前推一拍（字也打一拍）需要 din 提前一拍给，属接口改动。
