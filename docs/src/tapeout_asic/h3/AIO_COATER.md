# 镀膜一体机全球调研（2026-10-13）

**结论：**
- 玻璃 TFT 的三步镀膜（铝栅、RF 溅射 ZnO 或 IGZO、铝源漏）不需要热蒸发。一台**三靶溅射机**（2 个 DC 靶溅铝、1 个 RF 靶溅氧化物、Ar 和 O₂ 两路流量计、分子泵）就能一机做完。
- 这类机器国产约 **¥21–31 万**（挂牌价和高校中标价），海外最低的有据可查价格约 **¥39 万**（Moorfield，£41k 不含税），其余海外厂商多在 $125k 以上或只给询价。
- 推荐国产。首选成越 CY-MSH300-DDR，挂牌 ¥21–25 万，220 V 供电；泰科诺 JCP350 作对照，有高校中标价 ¥23.9 万。

**和平台比：** 按北大深研院每批 ¥3,000–4,500 算，要做约 50–80 批才回本（估算）。所以仍建议先去平台做出第一片，见 [FAST_FAB.md](FAST_FAB.md)。

调研只查了公开网页，没有询价、注册，也没有联系任何厂家。遇到验证码或限频就停下，没有绕过。原始调研和全部来源链接：

## 3. 选购要点

1. **用溅射镀铝。** 用 2″ 靶、DC 300–500 W，100–200 nm 只要几十分钟。热蒸发时铝会和钨舟合金化，舟很快损坏。
2. **流量计至少两路。** O₂ 比例要在 0–10% 内精确调，Ar、O₂ 各一路。CY-MSH300-III 和 TN-MS500S 的公开参数只写了 1 路，买时要加。
3. **钢网夹具。** 没有一家把它列为标准件，要自己做 50×50 mm 夹具。共焦斜射的机型（泰科诺 JCP350、Moorfield）掩模边缘的阴影会更宽，钢网要贴紧衬底。用第一片实测的渗开宽度（SPREAD）重新跑 `gen_tft_mask.py` 的检查即可。
4. **供电。** CY-MSH300-DDR 和 TN-MS500S 都是 220 V、4 kW，家里要有一路 25 A 左右的专线（估算）。JCP500 大概率要 380 V。
5. **出口限制。** 没查到针对小型研发镀膜机的对华禁令。日本 2023-07 起，23 类半导体设备对华出口要单独许可；美国的管制主要针对先进制程设备。买海外机时由卖方按具体型号判定。

## 4. 需要用户

1. 买不买，什么时候买。我建议等平台第一片测出晶体管以后再买。
2. 选机型。我推荐成越 CY-MSH300-DDR，泰科诺 JCP350 作比价。要你向厂家问清这几点：
   - 成交价，含不含靶枪、冷水机、运费；
   - 能不能加第 3 路流量计（第二路 O₂ 或 N₂）；
   - 衬底台能不能装 50×50 mm 的钢网夹具；
   - 交期和保修期；
   - 能不能去郑州或北京看机、送样试镀 ZnO。
   - 深圳科晶智达就在本地，可以先问三靶射频款的成交价，并带玻璃片和钢网去他们实验室试镀。
3. 家里的电（220 V 25 A 专线）、冷水机放在哪里、通风，以及氧气、氩气钢瓶的合规渠道。合规渠道见 [FAST_FAB.md](FAST_FAB.md) 第 3 节。
