# TapeOut transition ISA v1 / 状态转移规范

This specification defines the valid binary-netlist domain implemented by the ASIC. `golden.py` is an independent executable model; `chain_pin.json` pins BSC chain 56, block 121606648, processor proxy, beacon, implementation and runtime SHA-256. The implementation source is not explorer-verified. `chain_conformance.json` contains 16 matching public `eth_call` results; no transactions were submitted. An implementation upgrade requires renewed conformance.

Wire 0 is false, wire 1 true. Inputs occupy wires 2 through 1+nIn. Record i produces wire 2+nIn+i. Records are concatenated without padding: NAND is opcode 0 followed by two unsigned 24-bit big-endian wire indices (**7 bytes**); LATCH is opcode 1 followed by one such D index (**4 bytes**). There is no separate output-index table. The final nOut record wires, in ascending order, are the outputs (`last_outs`). nOut=0 returns empty output.

NAND evaluates NOT(A AND B); both operands must name an earlier wire. Each LATCH produces its old Q bit, ordered by occurrence of LATCH records. Its D may name any final wire, including a later record. After every record has been evaluated, all next-state bits are sampled from their D wires simultaneously. Outputs use the just-evaluated wire array, thus expose old Q where they reference a latch. A latch swap must swap both bits, without sequential overwrite propagation. Evaluation is one logical transition, independent of circuit depth or hardware clocks.

The Python API represents each bit as one byte 0/1. The chain ABI `step(uint256,bytes,bytes)` takes **packed** state and input bytes: bit i is bit i%8 of byte floor(i/8). It returns packed next-state then packed output. Canonical encoders zero unused high bits. Empty state means all-zero initialization. The conformance suite deliberately keeps Python bit arrays distinct from ABI packing. Arbitrary short, malformed or noncanonical encodings are outside v1; their chain behavior is not promised by this specification.

`Netlist.validate` rejects unknown opcodes, truncated records, negative/out-of-range counts, forward NAND dependencies and out-of-range latch D. Combinational cycles cannot arise in valid NAND records; latch feedback crosses a transition. Hardware import must additionally enforce its finite wire/latch capacities before running. Host netlist bytes and compact hardware schedule must be bound by a checked conversion and content hash; a smaller internal index is not a change to chain semantics.

Reset clears control and latch state. Explicit initial-state loading is supported for replay; reset is not an extra logical step. State/input/program must remain stable during a transition. A completion signal means next state and output are both available. Hash/trace claims must bind netlist hash, nIn/nOut, initial state, input, transition index and output; hardware identity alone proves none of these.

Validation: `python3 conformance.py` checks 10 fixture netlists, 1,792 fixture transitions and 3,200 transitions on 100 random DAGs, scalar versus independent predecessor evaluator and bit-sliced SIMD, plus four malformed decoder tests and simultaneous latch swap. Large fixtures are sampled, not exhaustively proven. `verify_chain.py` adds the pinned chain ABI check for #279/#280/#283/#284. This is an evidence boundary, not a formal equivalence proof of arbitrary EVM bytecode.
