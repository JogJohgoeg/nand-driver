# 常见问题

> 电脑够不够、要不要钱包、芯片能不能买、代币有没有权益。

## 核对要不要钱包？

不要。[自己核对](verify.md)的命令都是只读的。只有自己做电路、上链时才要钱包，见[做一个小电路](../build/index.md)。

## 我的电脑能跑门电路大脑吗？

页面打开后会先检查你的电脑，不够会直接说。

| 档位 | 配置 | 速度 |
|---|---|---|
| 能跑 | 8 GB 内存的普通笔记本，不用独立显卡 | 第一次打开约 3 分钟，之后每个字约 1.5 秒 |
| 跑得舒服 | 16 GB 以上内存，较强的显卡 | 能开「长回答」，每个字约 0.5 秒 |

- 浏览器：电脑上最新版 Chrome 或 Edge。Safari 要 18 以上，并在设置里打开 WebGPU。
- 手机暂时跑不动。
- 硬盘留 2 到 4 GB。

[打开门电路大脑](https://nand.aihashrate.stream/gate/)

## 每次打开都要等这么久吗？

不用。第一次会在你电脑上搭好电路并存起来，下次十几到二十几秒就能用。

这几种情况要重新搭：我们发布了新版本、你清了浏览器数据、用无痕窗口、硬盘空间不够。

## 跑一次，会在链上留下属于我的东西吗？

不会。门电路大脑只在你自己的电脑上跑，不上链。

它太大了：算一个字要约 2,600 亿个门，BNB Chain 上一颗电路要在一笔交易里写完，大约只能放 5,700 个门。所以链上只放小电路。

## 吟游诗人芯片造出来了吗？能买吗？

- 还没造，也不卖。
- 2026-10-12 设计通过了工厂要求的全部制造规则检查，完整设计图存上了 X Layer。
- 送哪家工厂、花多少钱、什么时候造，都还没定。
- 现在能做的：[从链上取回设计图](https://1-2-245.aihashrate.stream/bard/v8g/)，自己核对指纹。

## 吟游诗人和门电路大脑有什么不同？

- 门电路大脑：在你电脑的显卡上模拟门电路。
- 吟游诗人：拿去工厂造成实物的芯片。模型约 100 万个参数，整颗芯片 15 平方毫米。

## 能把我自己的小模型做成电路吗？

技术上可以，但我们的转换工具还不适合外部直接用，暂时没有公开教程。

- 参考花费：在 X Layer 上把一个约 3,800 个门的电路上链，净花费约 0.0023 OKB。
- 用别人的处理器，还要按对方的价格买晶体管。
- 从很小的逻辑做起，流程见[做一个小电路](../build/index.md)。

## 代币和电路、收入、芯片有绑定的权益吗？

没有。

- 代币合约只规定交易手续费怎么分：大部分进项目方的电路账户，一部分用于回购。
- 持币人对电路、工具收入、未来的芯片都没有合约约定的权益，没有分红，也没有收益分成。
- 买晶体管、开 Container 是做电路的使用费，不是投资。

## 普通人怎么参与最有用？

- 试用并反馈。门电路大脑页面「设置 → 测一测你的电脑」可以一键提交速度；遇到报错，把错误提示发给我们。
- 做一个自己的小电路，亲手走一遍上链流程。

## 名词

| 词 | 意思 |
|---|---|
| 门 / NAND | 最基础的开关电路。两个输入都是 1 才输出 0，其余输出 1。所有计算都能用它搭。 |
| 电路 | 很多个门按顺序连起来，完成一件事，比如加法、开车。 |
| 晶体管 | TapeOut 上的材料。电路里每个门用一个，上链前要买够。 |
| 流片 | 把电路正式写到链上。写上去后谁都能调用、核对。 |
| 处理器 / CPU | TapeOut 上的工厂。每个有自己的晶体管和价格，电路流片到某个处理器上。 |
| Container | 每个电路自带的链上账户，可以收款、放网页文件。这个网站就放在一个电路的 Container 里。 |
