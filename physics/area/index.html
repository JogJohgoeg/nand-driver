面积与存储：把电路放上链，按字节付钱

5.1直觉

把电路放上链，就像在芯片上占一块面积，按字节付钱：每存一个字节的代码 200 gas，再加上交易数据和官方处理器自己的记账。DOT32_T 有 3,829 个门、26,803 字节，在 X Layer 上发布用了 11,202,698 gas，其中存代码那一项占 48%。

5.2定义

定义本章用到的词
面积
电路在链上占的地方。网表存成数据合约的代码，按字节付钱，永久留着。
交易数据（calldata）
发交易时带上的字节。只进链的历史，合约之后读不到。
存储字
合约自己的「寄存器」，每个 32 字节。读、写、清都要钱。
返还
把存储字清成 0，会退一点 gas，在交易结束时才结算。
发布
把网表发上链、登记成一颗电路的那笔交易。本书只读已有的发布回执，不模拟、也不调用发布用的那个函数。
回执
交易上链后节点给的记录，里面有这笔实际用了多少 gas。

定律十说清掉 k 个存储字，实扣 = 返还前用量 − min(4,800 × k, 返还前用量的五分之一)，页面在 k = 1、4、20、100 上逐个相等。我（反方）在 BSC 上用 eth_simulateV1 模拟自己写的直线代码（每个字一条「PUSH1 值、PUSH1 槽号、SSTORE」），先照页面那一种复现：k 个字开始时是 1，清成 0，四个 k 的实扣是 21,206、32,820、96,896、417,280，和页面一个不差；所有情形里退的 gas 都没超过返还前用量的五分之一。

换一种同样是「清掉 k 个字」的情形就不对了：这 k 个字在交易开始时是 0，同一笔里先写成 1、再清回 0。k = 1 时实扣 34,570，定律十的式子给 38,412，多算了 3,842；k = 4 时实扣 87,879，式子给 90,648，多算 2,769；k = 20、100 时两边都被五分之一的上限压住，才又相等。差在每个字退多少：交易开始时是 0 的字，先写后清退的是 19,900（EIP-3529 的规则），不是 4,800；用 19,900 算，四个 k 都一个 gas 不差。按我事先写的线判削弱：「只退两成」那个上限在所有情形里都成立，但「每个清掉的字退 4,800」只对交易开始时非零的字成立。

另外照实报：把字改了再改回原值（开始 1 → 2 → 1，或 1 → 0 → 1），交易结束时一个字也没清掉，也有返还，每个字 2,800（k = 1 时返还前 26,112、实扣 23,312）。建议定律十写明 k 是「交易开始时非零、结束时为 0 的字」，再补一句：开始时为 0 的字先写后清每个退 19,900，改回原值的每个退 2,800，都受五分之一上限。X Layer 两家官方节点都不开放 eth_simulateV1，这一条只量了 BSC。

5.4怎么量出来的

  1. 定律八：只读已有的发布回执，不发交易，不模拟发布函数。
    • 回执里有实际用的 gas；网表从链上读回来，数出与非门、锁存、字节数、块数和零字节。
    • 先按协议的价算出协议那部分，剩下的对（固定、每个与非门、每个锁存、每块）做最小二乘。
    • 含子电路调用的发布不进拟合。X Layer 只有 DOT32_T 那 1 笔，留作样本外。
  2. 定律十：用 eth_simulateV1 模拟一笔清掉 k 个存储字的交易，读模拟回执里的用量，和按式子算的比。
  3. 常数：都是在一次只读调用里，用一小段代码现量的。一个合约最多 24,576 字节代码，24,577 字节就建不出来。

5.5例题

例题 1DOT32_T 在 X Layer 上发布用了多少

X Layer 处理器 0xa93e807f… 的第 3 号电路 DOT32_T：3,829 个与非门、0 个锁存，网表 26,803 字节，分 2 块；整笔交易数据 26,948 字节，其中零字节 12,422。回执上实际用了 11,202,698 gas。

  1. 协议那部分：21,000 + 4 × 12,422 + 16 × 14,526 + 32,000 × 2 + 200 × 26,805 = 5,728,104。
  2. 官方处理器的记账：45,875 + 1,370.3 × 3,829 + 107,506 × 2 = 5,507,906。（系数用结果文件里的全精度。）
  3. 合计 11,236,010，比回执高 33,312，估高 0.30%。
  4. 分块那几项：2 块的建合约、记账和前缀字节一共 279,413，占 2.5%。大头是存代码：5,361,000，占 48%。
例题 2一笔交易最多能发布多大的电路
  • BSC 单笔上限 16,777,216。照定律八，假设网表里零字节占 44%（大网表的中位数），平网表最多约 5,774 个与非门。
  • 更大的电路，要么拆成子电路，父电路只放调用记录（第 2 章定律十二）；要么放在 X Layer，单笔按块上限 2.1 亿算（只实测到 1 亿）。

5.6什么时候不成立

这条会不成立照实写
  1. 只用了已有的回执。规矩不许模拟发布函数，所以样本只能是别人已经发过的：BSC 51 笔、X Layer 1 笔。含子电路调用的发布没量。
  2. 记账那四个系数是 BSC 回执拟出来的。X Layer 只有一笔能对，差 −0.30%；按笔留一，BSC 最大差 7.5%。
  3. X Layer 那份是换了节点才量到的。X Layer 官方节点不给模拟，四档都回「HTTP 403」；换 drpc 节点再量，四档的实扣和预测逐个相等。
  4. 交易数据为主时另有地板价（每字节非零 40、零 10）。发布电路时碰不到：52 笔回执里（BSC 51 笔、X Layer 1 笔），地板价最高只到实际用量的 11%。两链都跟了这条：反方对三笔纯数据交易用模拟核过 BSC，实扣正好等于带地板的数。要注意，节点的 eth_estimateGas 对这种交易会多报约 1%，要实扣的数按协议算或用模拟。（常数表页反方第 8 条）
  5. 适用范围：官方处理器；不含子电路调用的发布；锁存为主的发布会估高约 12%（见定律八的更正）。

5.7小结

  • 发布一颗电路 ≈ 存代码（每字节 200）+ 官方处理器每个门约 1,370 的记账 + 交易数据 + 每块的建合约和记账。
  • DOT32_T 在 X Layer 上发布用了 11,202,698 gas，存代码占 48%；定律八估高 0.30%。
  • BSC 一笔交易最多发布约 5,774 个与非门（平网表；分层电路一笔能建几十万门）。
  • 清存储字最多只退用量的五分之一，而且交易结束才退。
